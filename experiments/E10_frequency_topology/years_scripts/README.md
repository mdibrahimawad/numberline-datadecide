session (`/home/user/mdibrahimawad/topology_number_line/data/crystal_vectors`, the SlimPajama
counts under `/home/user/numberline-datadecide/results/...`); edit `VEC`/`CNT` at the top to
rerun. `pass1.py` years/round vs twins, `pass1b.py` years vs ~150 ordinary windows,
`pass1c.py` decade clustering. Run from this folder: `python pass1.py out.csv`, `python pass1b.py`,
`python pass1c.py`.
